# GHOST file-removal audit

This audit covers the active repository imports, command scripts, tests,
packaging inventories, dynamic dispatch, and native-library lookup. Removal
candidates remain on disk.

| Candidate | Finding | Removal condition |
| --- | --- | --- |
| `cpu_checked_lu.py` | No application or test imports. Its `CheckedLU` class is a small adapter over `ghost_backend.linalg.dense.DenseFactor`. The source inventory still lists it. | Remove the file and its `GHOST_SENTINELS` entry together. Check any separately maintained scripts that explicitly import `CheckedLU`. |
| `__pycache__/` directories and `.pyc` files | Generated Python bytecode, including cached versions of the relocated modules. | Safe to delete with GHOST closed; Python recreates needed caches. These are build/runtime artifacts, not dead source modules. |

`cpu_streaming.py` is a consolidation candidate, **not currently dead**.
`ghost_backend.execution.cpu.select_solver` imports it during CPU dispatch.
It re-exports four implementations from `ghost_backend.twod.solver`. Remove it
only after consolidating that dispatch and testing the CPU path.

## Keep these files

- `ghost_backend/validation/cylinder.py` and `sphere.py`: independent analytic
  references used by the physics tests.
- Root command scripts: several have no Python importers because users and
  subprocesses execute them directly.
- `bor_stream_kernel.c` and the matching `.dll`/`.so`: source and runtime
  artifacts for native BoR acceleration. The Windows DLL is used on this host.
- `_ghost_dataclasses.py`, its license, and `THIRD_PARTY.md`: required support
  for the tested Python 3.6 environment.
- The public import entry modules listed in `README.md`: retain the established
  solver and workflow APIs.
- `ghost_backend/linalg/hierarchical.py`, `compressed/`, and
  `twod/formulations/`: active selectable matrix and material paths.

An absent direct importer is insufficient evidence for removal. This audit
found one source-file removal candidate, one active consolidation candidate,
and generated bytecode that can be cleared. Geometry files, results, and
experiment snapshots are outside this removal recommendation.
