# Project audit — 12 September 2026

Read [REPORT.md](REPORT.md) for findings, tab-by-tab coverage, exact test counts and reproduction commands.

This is an audit evidence package. It does not implement the reported fixes.
The audit examined a working tree with existing uncommitted application changes;
`source-snapshot.json` records the inspected file hashes. Results describe that
snapshot, not an assertion that every revision of the branch has the same behavior.
The audit-only commit leaves those application changes unpublished. Some probes
depend on modules in that audited working tree and cannot run against the older
base commit alone. Relevant defect locations are preserved in `SOURCE_CONTEXT.md`.

The existing suite reported 1,987 passed, 1 failed and 4 skipped tests.
Twenty-five independent workflow probes passed. The added expected-behavior
regression file intentionally remains failing for the three reported application
defects; do not count it as a successful acceptance run.

Scripts are located relative to this repository. UI probes use Qt offscreen and
the Windows Segoe UI font. The PowerPoint probe requires Windows desktop
PowerPoint and a fresh output filename. Local machine paths in copied text logs
have been normalized; screenshots preserve the original rendered evidence.

Synthetic datasets, generated scripts, office files and transient settings are
regenerated by the probes and are not included in this evidence commit. Rerunning
checks replaces the copied result logs; preserve this commit for historical results.
